1. Product Introduction 
What This Product Is 
This project is a modern frontend framework and theme compiler for WordPress. 
It allows developers to build WordPress themes using modern JavaScript tooling such as: 
● React 
● TypeScript 
● Tailwind CSS 
● shadcn/ui components 
● Vite 
and then compile/export the project into a native installable WordPress theme. 
The goal is to modernize WordPress frontend development without requiring developers to 
deeply learn PHP-based theme architecture. 
2. The Problem 
Modern frontend developers avoid WordPress because: 
● WordPress theme development is heavily PHP-based 
● Existing builders are restrictive 
● Developer experience is outdated 
● Styling systems are inconsistent 
● Reusability is poor 
● Frontend tooling feels disconnected from modern standards 
Current WordPress builders focus mostly on: 
● drag-and-drop editing 
● no-code users 
● visual design 
But there is a major gap: 
developer-first WordPress frontend engineering. 
3. Vision Statement

9. Architecture Principles 
Important Principle #1 
This product does NOT run Next.js inside WordPress. 
Instead: 
React is used as the authoring layer. 
The framework compiles React projects into native WordPress-compatible themes. 
Important Principle #2 
The framework should minimize runtime JavaScript where possible. 
Goals: 
● fast loading 
● low hydration 
● SEO-friendly output 
● minimal frontend overhead 
Important Principle #3 
Avoid proprietary lock-in. 
Generated code should remain: 
● editable 
● portable 
● transparent
